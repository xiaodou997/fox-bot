## 3. 持续宿主 smoke 的真实输出

最终实现的独立 smoke 运行用时 2.453 秒，输出如下。这个值是整段短时测试耗时，不是回复延迟、性能门槛或持续运行时长承诺。

```json
{
  "loopback_only": true,
  "synthetic_only": true,
  "native_chat_operations": 0,
  "first_run_jobs": 3,
  "first_run_mock_sends": 2,
  "feedback_acked": 3,
  "replay_jobs": 0,
  "replay_mock_sends": 0,
  "elapsed_seconds": 2.453
}
```

三次生成包括一个在网络响应前暂停取消的任务，所以只有两次模拟发送。回执包含相应的取消和输出事实；有一次 503 后自动补偿，没有再次发送。相同状态目录重启、显式 resume、重放同一事件后，生成与模拟发送均为零。

脚本在退出临时目录上下文前确认所有子进程已终止，之后关闭服务和读线程。单独的 Rust 跨进程测试保留 stdin 打开仍发送 stop，验证进程退出和零活动作业；同时验证两处不同账本无法绕过同一执行锁。没有永久留下正在运行的宿主或 HTTP 测试服务；共享的空锁文件按设计保留，不用删除它的方式释放执行权。

## 4. 安全路径的可执行证据

| 范围 | 验证结果 |
| --- | --- |
| 暂停与旧观察 | 暂停前排队/暂停期间的观察不会在恢复后触发积压回复；新消息可继续处理。 |
| 网络与停止 | 网络期间控制仍可响应；取消结果不发送；结束前回收 JoinSet 作业。 |
| 会话与配置 | 配置绑定范围之外的输入拒绝；不同 HTTP 实例配置不能误配给宿主；恢复不偷偷重新启用 handoff 会话。 |
| 加密与凭据 | 缺失/不可用凭据不创建明文兜底；正确密钥重开，错误密钥、篡改、明文导入均拒绝。 |
| 数据库/WAL | 指定合成正文在磁盘数据库/WAL 中不可搜索到；解锁后可恢复对应内容。此检查不等于完整密码学审计。 |
| 完整安全入口 | 注入隔离测试凭据经 config.open → encrypted Runtime → Host → loopback HTTP → mock send → reopen 跑通。 |
| 原生钥匙串 | 仅测试随机 FoxBot 条目；没有查询其他凭据。删除结果已核对，未给用户创建长期 API token 或数据库密钥。 |

## 5. 本轮发生的失败与修正

保留以下事实，不把最终绿色结果描述为从未失败：

1. 初次 Clippy 报告两个可合并 if，修正后相同检查重新通过。
2. 提交后第一次完整复跑中，既有 `killed_http_process_recovers_with_cancellation_receipt_and_no_chat_send` 等待请求超过原3秒预算。原夹具丢弃子进程 stderr，无法从当次记录确定最初为何没有及时到达；不能武断宣称是业务故障或仅是机器慢。
3. 为该故障注入测试分离启动与网络超时：等待实际请求到达，同时检查子进程提前退出并保留诊断；测试专属启动预算15秒、请求预算10秒且只有一次尝试，不改变产品重试配置。修正后完整103项通过，修正提交后又完整复跑通过。
4. `git diff --check` 曾发现两处新增 EOF 空行，已按文件版本护栏修正并重新检查。
5. 依赖版本提取首次使用 tomllib 失败，本机 Python 没有该模块；改为仅读取 Cargo.lock 的标准库提取，不安装额外库、不修改系统环境。
6. WebCodex 个别暴露 schema 与服务端不一致，以及目标展示卡无直接调用入口，相关请求被拒绝；没有因此绕过文件版本护栏或把未执行动作记为完成。
